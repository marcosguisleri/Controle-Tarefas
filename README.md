# ✅ Sistema de Controle de Tarefas (Python CLI)

Um projetinho simples, mas funcional, feito como atividade extra para a disciplina de **Tópicos em Linguagem de Programação**.  
O objetivo é permitir que o usuário cadastre tarefas, visualize a lista e marque tarefas como concluídas — tudo isso direto no terminal e com salvamento automático.

---

## 🧠 Conceitos aplicados

- ✅ Programação orientada a objetos (POO)
- ✅ Manipulação de arquivos JSON
- ✅ Laços de repetição e condicionais
- ✅ Funções e métodos organizados
- ✅ Tratamento de exceções
- ✅ Boas práticas e variáveis em **português com camelCase** (sim, estilo 🇧🇷💻)

---

## 📦 Funcionalidades

- Adicionar uma nova tarefa
- Listar todas as tarefas (exibindo status)
- Marcar tarefa como concluída
- Dados persistidos em um arquivo `.json`
